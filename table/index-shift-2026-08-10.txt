# 核 (C) の添字ずれ — 4 例の実測 (2026-08-10)
#
# 目的: 自己分岐する組み立て `fsAsm : Term → Nat → Term` は、各分岐で
#       「内側の列のどの添字を使うか」を計算しなければならない。
#       veblen2 が 3 例でずれが 3 通りになると報告し、そこから
#       「ずれを項から読むには isFP が要る = §15.3 の費用の再開」
#       という範囲の判断が生じた。判断の前に測る。
# 方法: 行と内側の項の **両方を行列から** 読む。同じ道具 (Trans.oR)、同じ添字。
#       ライブラリの列関数 (ofNat / tower / fsC) は使わない — それらは
#       添字の基準が別々なので、比較にそれを混ぜるとずれの原因が判別できない。
#       C2 のとおり、列を固定するのは行列である。
# 注意: `Trans.o?` は使わない。撤回済みで ζ₀ 以上で誤る (SqV.lean §1.1)。

== 測定 ==

  行 (行列)                       内側 X (行列)          ずれ
  ------------------------------- ---------------------- ------
  ε_ω      (0,0)(1,1)(2,0)        ω     (0)(1)            -1
  ε_{ω²}   (0,0)(1,1)(2,0)(2,0)   ω²    (0)(1)(1)          0
  ε_{ω^ω}  (0,0)(1,1)(2,0)(3,0)   ω^ω   (0)(1)(2)          0     ← 追加
  ε_{ε₀}   (0,0)(1,1)(2,0)(3,1)   ε₀    (0,0)(1,1)        +1
  ε_{ζ₀+1} (0,0)(1,1)(2,1)(1,1)   ζ₀    (0,0)(1,1)(2,1)   該当なし ← 追加

行の第 n 展開 == φ̄(1, X の第 (n+ずれ) 展開)、n ≤ 3 で検査。

== 5 行目は反例ではない。核 (C) の外である ==

ζ₀ は φ̄1 の不動点なので、φ̄(1, ζ₀ より下の何か) < ζ₀ < φ̄(1,ζ₀) となり、
どの添字でも届かない。§15.18 の一様上界と同じ現象である。
この行はテンプレート (B) が担当する。したがってこれは**陽性対照**として働く
— 添字ずれの問いは核 (C) の内側でしか生じない、ということを示している。

== 帰結: isFP はずれを計算できない ==

  ω     ω^· の不動点でない   ずれ -1
  ω²    不動点でない          ずれ  0
  ω^ω   不動点でない          ずれ  0
  ε₀    不動点である          ずれ +1

`isFP` は 2 値の述語なので、**3 通りの値を出せない**。
{ε₀ = +1} と {ω², ω^ω = 0} は分けられるが、ω の -1 は分けられない。

そして ω の -1 には**別の既知の原因があり、それは不動点性ではない**:
`fsC ω n = ofNat (n+1)` (1 始まり) 対 行列展開 (0 始まり)。
定理 `fsC_omega` (§15.12.1) が既にこれを述べている。

したがって §15.3 の費用を払っても、ずれの計算は**閉じない**。
費用は実在し、効果は部分的である。

== 訂正 (2026-08-10、同日中) — 上の 2 対 3 の議論は成り立たない ==

veblen2 が certsound の独立な発見 (a ≠ 0 で梯子の後のブロックは添字の ω 指数を
表す。ε 数では ω^ε₀ = ε₀ なので**不可視**) を受けて分解し直した。実測:

  * **ω の -1 はずれではない。**n = 0 で行の内側添字は b[-1] を要求するが、
    それは存在しない。ω の -1 は b の列をずらしたものではなく**別の添字規約**で、
    原因は既に名前と証明を持つ (`fsC_omega`: `fsC ω n = ofNat (n+1)`、1 始まり)。
  * **ζ₀ の「どの添字も効かない」は核 (C) の場合ではない。**その行は (B)。
  * 核 (C) の実際のずれの場合は **2 値 2 クラス**で、ε 数性が正確に分ける
    (ω², ω^ω → 0 ; ε₀ → +1)。

したがって「isFP は 2 値、ずれは 3 通り」という**上の論証は死んでいる**。
証拠に基づくと記録した判断は、その証拠より長生きしてはならない。

== それでも判断は変わらない。ただし理由が変わる ==

**(b) のまま。§15.3 の費用は開かない。**新しい理由:

1. 分ける述語は **ε 数性であり、それは構文的**である (§15.18 の判定基準、
   `φ̄(a,·)` で a ≠ 0)。`isFP`/`phiShifted` の import は**そもそも要らない**。
   つまり (c) は「払うべきか」ではなく「払う対象が存在しない」に変わった。
2. 核 (C) の witness は 0 が 2 例、+1 が 1 例。**C4 が信用するなと言う数**である。
3. そして規則が見つかっても買えるのは**自己分岐という利便性だけ**である。
   出荷済みのものは呼び出し側からずれを受け取っており、
   §15.22 が (b) として組み上がっている。

== 判断 ==

**(b) 形の分岐だけを組み立て、ずれは引数として受け取る。**
§15.3 の費用は開かない。理由は好みではなく上の測定である。

出荷済みのものは影響を受けない: 各形の定理は呼び出し側からずれを受け取っており
(`lim_clauses_shift`, §15.12.2)、certsound の分岐表は各定理が渡す `fs` を
ずれ込みで名指ししている。組み立ては自己分岐という利便性だけの話だった。

== 未確認 ==

* 核 (C) の witness は 4 例。ずれの値は 3 通り。`isFP` 以外の予測子は
  探していない。「予測子は無い」ではなく「探していない」である。
* ε₀ の +1 の**原因**は特定していない。ε₀ の行列列が 1 から始まり
  (1, ω, ω^ω, …)、行がその最初の値を飛ばす、という事実までしか見ていない。
  飛ばす理由は共終性からは強制されない (飛ばさなくても共終である)。
  行列が決めている、というのが今わかっていることの全部である。
