# ζ₀ より上・Γ₀ 未満の Veblen 行 — 展開の測定 (2026-08-10)
#
# 目的: この 4 行は候補ティア (ev := "oR") だが、値は φ̄ のみで ψ・Z を含まない。
#       つまり Veblen 帯の続きであり、証明書キャンペーンの次の区間である。
#       次に担当する者が「設計する前に測る」規律を守れるよう、先に測っておく。
# 方法: Trans.oR (BMS.expand M n), n ≤ 3。oR は候補ティアであり定理ではない。
#       値が何であるべきかを教えるが、証明の正当化には現れてはならない。
# 注意: constitution C2 のとおり、列を固定するのは行列である。ここに書いた列は
#       行列から読んだものであって、項の構文から推測したものではない。

== 測定結果 (4 行すべて kind = lim) ==

(0,0)(1,1)(2,1)(2,0)        ζ_ω = φ̄(2,ω)
    ζ₀, ζ₁, ζ₂, ζ₃              fs n = φ̄(2, n)
    -> テンプレート (C) の a = 2 版。ε_ω が (C) の a = 1 版だったのと同型。

(0,0)(1,1)(2,1)(2,1)        φ̄(3,0)
    ζ₀, φ̄(2,ζ₀), φ̄(2,φ̄(2,ζ₀)), …   fs = φ̄2 の反復
    -> テンプレート (B) の u = 2 版。ζ₀ が (B) の u = 1 版だったのと同型。

(0,0)(1,1)(2,1)(3,0)        φ̄(ω,0)
    φ̄(2,0), φ̄(3,0), φ̄(4,0), φ̄(5,0)      fs n = φ̄(n+2, 0)
    -> **第 1 引数が動く。既存の 3 テンプレートのいずれでもない。**

(0,0)(1,1)(2,1)(3,0)(4,1)   φ̄(ε₀,0)
    φ̄(ω,0), φ̄(ω^ω,0), φ̄(ω^(ω^ω),0), …   fs n = φ̄(tower (n+1), 0)
    -> 同じく第 1 引数が動く。動き方は §9 の tower。

== 帰結: 新しいテンプレートは 1 つだけ ==

4 行のうち 2 行は、既存テンプレート (B)/(C) の第 1 引数を 1 から 2 に替えただけである。
これらのテンプレートは既に第 1 引数を引数として取っているので、追加作業は
側条件の放電のみと見込まれる。

残る 2 行が要求するのは、(C) の**鏡像**である:

```
(C)  fs n = φ̄ a (g n)        第 2 引数に内側の列を入れる   — 証明済み
(C') fs n = φ̄ (g n) b        第 1 引数に内側の列を入れる   — 未着手
```

φ̄(ω,0) では g = ofNat(n+2)、φ̄(ε₀,0) では g = tower(n+1)。
どちらも内側の列は既にファイルにある (`ofNat`, §9 の `tower`)。

== 未確認 ==

  第 1 引数を動かす場合にどれが効くかは (C) の場合と異なる可能性がある。

* Γ₀ 以降 (ψ・Z が現れる領域) は対象外。そこは別の問題である。
